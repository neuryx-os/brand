# Política de marca do Neuryx

O nome **Neuryx** e os logotipos contidos neste repositório (símbolo, ícone e
lockups) são marcas do projeto Neuryx. Os arquivos deste repositório **não**
estão sob licença de código aberto.

## Uso permitido sem autorização

Você pode usar o nome e o logo, **sem alterações**, para se referir ao projeto
Neuryx — por exemplo, em artigos, apresentações, materiais didáticos, listas de
distribuições Linux ou links para o projeto —, desde que o uso não sugira
patrocínio, endosso ou vínculo oficial que não exista.

## Uso que exige autorização

Precisam de autorização prévia por escrito:

- versões modificadas do nome ou do logo (cores, proporções, elementos,
  combinações com outras marcas);
- uso comercial, incluindo produtos, serviços, brindes e materiais de
  divulgação de terceiros;
- uso em distribuições, imagens ou pacotes derivados do Neuryx que não sejam
  os oficiais.

Para pedir autorização, escreva para **rodrigo@w3ti.com.br**.

## Distribuições derivadas

O código do Neuryx é software livre, sob as licenças indicadas em cada
repositório. Quem distribuir uma versão modificada deve remover ou substituir
o nome e o logo do Neuryx, salvo autorização.
